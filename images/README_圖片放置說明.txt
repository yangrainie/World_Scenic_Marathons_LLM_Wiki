世界必跑絕景馬拉松 HTML 簡報 - 圖片放置指南
========================================================================

您可以直接將賽事照片、風景照或地圖圖片放入此 `images/` 資料夾中。
簡報已設定「自動偵測顯示」功能：
- 如果圖片檔案存在，簡報會以極簡雜誌風格自動排版呈現。
- 如果圖片尚未放入，簡報會自動優雅隱藏圖片區塊，完全不會出現破損圖標（Broken Image Icon）。
